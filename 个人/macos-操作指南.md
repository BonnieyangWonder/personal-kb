## ⌨️ 修饰键对照（先记住这个）

| Mac 符号 | Mac 键名 | ≈ Windows 键 |
|----------|---------|--------------|
| ⌘ | Command | Ctrl |
| ⌥ | Option | Alt |
| ⌃ | Control | Ctrl（少用） |
| ⇧ | Shift | Shift |
| Fn | Fn / 🌐 | Fn |

> **核心记忆**：Windows 的 `Ctrl` = Mac 的 `⌘`。大部分快捷键把 `Ctrl` 换成 `⌘` 就行。

---

## 🗑️ 删除文件

| 方式 | 操作 | 对应 Windows |
|------|------|-------------|
| 拖到废纸篓 | 拖文件到 Dock 栏的 🗑️ 图标 | 拖到回收站 |
| 快捷键删除 | `⌘ + Delete` | `Delete` 键 |
| 永久删除（跳过废纸篓） | `⌘ + ⌥ + Delete` | `Shift + Delete` |
| 清空废纸篓 | Dock 右键废纸篓 → 清空，或 `⌘ + Shift + Delete` | 清空回收站 |

> Mac 键盘的 `Delete` = Windows 的 `Backspace`。**前向删除**（删右边字符）：`Fn + Delete`

## 📁 文件与窗口管理

| 操作 | 快捷键 | Windows 对应 |
|------|--------|-------------|
| 复制 | `⌘ + C` | `Ctrl + C` |
| 粘贴 | `⌘ + V` | `Ctrl + V` |
| 剪切（移动文件） | `⌘ + C` → `⌘ + ⌥ + V` | `Ctrl + X → V` |
| 撤销 | `⌘ + Z` | `Ctrl + Z` |
| 全选 | `⌘ + A` | `Ctrl + A` |
| 重命名文件 | 选中 → `Enter` | `F2` |
| 打开文件 | `⌘ + O` 或 `⌘ + ↓` | `Enter` |
| 新建文件夹 | `⌘ + Shift + N` | `Ctrl + Shift + N` |
| **快速预览**（强烈推荐） | 选中文件 → `Space` | 无 |
| 关闭窗口 | `⌘ + W` | 关标签/窗口 |
| 退出程序 | `⌘ + Q` | `Alt + F4` |
| 切换应用 | `⌘ + Tab` | `Alt + Tab` |
| 同一应用内切换窗口 | `⌘ + ~` | `Ctrl + Tab` |

> 🔑 **关键区别**：`⌘ + W` 只关窗口，程序还在后台（Dock 栏有小点）。`⌘ + Q` 才是彻底退出。

## 💡 新手必知：Mac vs Windows 的核心逻辑差异

1. **菜单栏在屏幕顶部**，不在窗口上。切换应用菜单栏内容跟着变。
2. **关闭窗口 ≠ 退出程序**。Dock 栏下面的小圆点 = 程序还在运行。
3. **最小化 ≠ 消失**。最小化的窗口缩到 **Dock 右侧（分隔线右边）**，点击缩略图即可还原。也可以用三指上推打开「调度中心」看所有窗口。
4. **安装 App**：`.dmg` 拖到 `应用程序` 文件夹。**卸载**：从 `应用程序` 拖到废纸篓。
4. **没有盘符**（无 C: D: 等），所有文件在 Finder 里统一管理。
5. **Enter = 重命名**，打开文件用 `⌘ + O` 或 `⌘ + ↓`。
6. **没有「剪切」文件的直接快捷键**，用 `⌘ + C` 复制后 `⌘ + ⌥ + V` 移动。

## ⌨️ 蓝牙键盘：修饰键对调

用 Windows 布局的键盘连 Mac 时，按键印的字和实际功能不匹配：

| 键盘上的字 | Mac 实际需要 |
|-----------|-------------|
| Ctrl | ⌃ Control |
| Win | ⌘ Command |
| Alt | ⌥ Option |

**建议对调**： → 系统设置 → 键盘 → 键盘快捷键 → **修饰键** → 选你的蓝牙键盘 → 把 `Option` 和 `Command` 互换。

> 换完后按键盘上的 `Win` 键就等于 Mac 原生 `⌘`，肌肉记忆不用改。

## 🖥️ 外接显示器：Mac vs Windows 差异

### 没有 `Win + P` 切换模式

Windows 按 `Win + P` 弹出切换面板。**Mac 没有**。插上默认就是扩展模式，改设置去：

>  → 系统设置 → 显示器 → **排列**

### 主屏幕怎么设？

Mac 上主屏幕的标志是 **顶部有白色菜单栏的那块屏**。

设置方法：在显示器排列页面，**把白色小条从一块蓝方块顶部拖到另一块**：

```
  [  ]  [白条█]    ← 拖动白条就切换主屏
```

### 外接屏全屏会变灰？

macOS 的绿色按钮全屏会独占一个「桌面空间」，另一块屏灰掉。**关掉这个行为**：

> 系统设置 → 桌面与程序坞 → 关闭 **「每台显示器使用单独的空间」**

### 没有原生窗口分屏快捷键

Windows 的 `Win + ←/→` 快速分屏，Mac 没有。替代方案：

| 方式 | 操作 |
|------|------|
| 手动 | 悬停窗口绿色按钮 → 选「将窗口拼贴到屏幕左侧/右侧」 |
| **推荐装 Rectangle**（免费） | 装完就能用 `⌘ + ⌥ + ←/→` 快速分屏 |

### Dock 在哪块屏？

Dock 默认只在主屏底部。要让它出现在另一块屏：光标移到那块屏底部停一下。

## 🔧 常用系统设置建议

- **右键**：系统设置 → 触控板 → 辅助点按 → 设为「双指轻点」
- **三指拖移**：系统设置 → 辅助功能 → 指针控制 → 触控板选项 → 启用拖移
- **Dock 自动隐藏**：系统设置 → 桌面与程序坞 → 自动隐藏
- **Hot Corners（触发角）**：系统设置 → 桌面与程序坞 → 触发角，鼠标甩到屏幕角落自动执行操作
